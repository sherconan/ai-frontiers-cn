# 每日精选 · 2026-04-12

> **Claude Opus 4.6：旗舰回到「技术天花板」**
> 来源：**Anthropic** · [Claude Opus 4.6：Anthropic 最强推理模型的重大升级](../anthropic/claude-opus-4-6)
> **一句话：** Opus 4.6 在编程、智能体与长上下文三条线上全面升级，Opus 系列首次跨入百万 token 上下文窗口，在 GDPval-AA 等经济价值基准上以约 144 Elo 压过 GPT-5.2。

## 速览

Anthropic 于 4 月 12 日发布 **Claude Opus 4.6**，这是 Opus 系列继 4.5 之后的关键换代。升级集中在三件事：

1. **推理深度**：Humanity's Last Exam 跨学科推理领先所有前沿模型；BrowseComp 在「难找信息定位」上取得最佳表现。
2. **智能体执行**：Terminal-Bench 2.0（智能体编程）取得最高分；GDPval-AA（经济价值知识工作）以约 144 Elo 超过 GPT-5.2。
3. **长上下文**：Opus 系列首次引入百万 token 上下文窗口。

产品侧同步接入 Claude.ai 的 Projects / Artifacts / Skills，并成为 Claude Code 的默认旗舰模型。

## 🔑 核心洞察

- **「百万 token × 长推理链」** 是 Opus 的底层变量。推理模型的竞争点已经从单轮智商，转向「长上下文里维持链式一致性」的能力。
- **GDPval-AA** 这种「经济价值工作任务」基准正在取代 MMLU/HumanEval——评估范式在变，从考试变成工作台。
- Anthropic 在用 Opus 把被 GPT-5 一度夺走的「顶配旗舰」心智重新抢回来。

## 一句话推荐

做 agent/IDE/长任务工作流的，这是 2026 Q2 必测 baseline。
